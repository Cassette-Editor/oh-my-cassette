## [0.5.0](https://github.com/Cassette-Editor/oh-my-cassette/compare/v0.4.19...v0.5.0) (2026-10-21)


### ⚠ BREAKING CHANGES

* The plugin is now a stdio bridge to the Cassette MCP service, and the tools your agent sees are the service's. Sign in again with `uvx oh-my-cassette==0.5.0 login`; the 0.4 tools, sessions, music search and Hermes gateway are gone. See "Upgrading from 0.4" in the README ([#88](https://github.com/Cassette-Editor/oh-my-cassette/issues/88)) ([0c5996e](https://github.com/Cassette-Editor/oh-my-cassette/commit/0c5996e798bb449781a35dd418ba366601821e6e))

### Features

* Published on PyPI: hosts start it with `uvx oh-my-cassette==0.5.0`.
* `login`, `status` and `logout` sign in through the browser and keep one saved connection in the system keyring.
* Local files are transcoded with ffmpeg into the renditions the service declares; each file uploads while the next is prepared, in parts, four transfers at a time, and an interrupted upload resumes when the file is imported again.
* Exports download into `cassette-exports/`, resuming an interrupted download.
* The bridge reconnects after a deploy, sends a turn again once when the connection drops, and while the service cannot be reached lists only `cassette_bridge_status`, which says why.
* `oh-my-cassette check` verifies a Cassette MCP service against the bridge contract.

## 0.1.0 (2026-07-16)

Baseline release.

- Cassette video-editing plugin for Hermes Agent: media ingestion, asset
  manifests, edit-prompt preparation, and browser-driven Cassette jobs with
  progress notifications back to the chat gateway (QQ, Telegram, WeChat, web).
- Smart BGM matching via Jamendo and exact-BGM sources, plus the
  `cassette-video-edit` skill and `/cassette` commands.
- Guided installer (`scripts/install_plugin.py`), install diagnostics
  (`scripts/diagnose_install.py`), and a hosted web demo under `web_demo/`.
